## Hardware meaning

`0x1F801084` is `DMA0_BCR`, the block control register of DMA channel 0: low
half = block size in words, high half = block count. The unit writes
`((size >> 5) << 16) | 0x20`, i.e. `size / 32` blocks of 32 words — 0x20 words
is one 128-byte MDEC macroblock row unit.

## Correct C type

`u32 *`.
