## Hardware meaning

`0x1F8010F4` is `DICR`, the DMA interrupt control register:

* bits 24–30 — per-channel interrupt flags (which channel finished a transfer)
* bit 23 — master interrupt enable
* bits 16–22 — per-channel interrupt enables
* bit 15 — force interrupt
* bit 31 — the combined interrupt request seen by the CPU

The game clears the register at startup (`func_80091CC0`), reads the channel
flags with `(*gDmaInterruptCtrlPtr >> 24) & 0x7F`, acknowledges a channel with
`&= (1 << (channel + 24)) | 0xFFFFFF`, and checks `0xFF000000 == 0x80000000`
or bit 15 to detect a spurious or forced request. Bit numbering follows public
PlayStation documentation.

## Correct C type

| unit | declaration |

| `func_80091D0C` | `volatile u32 *` |
| `func_80091E8C` | `unsigned int *` |
| `func_80091CC0` | `s32 *` (only a full-word store of 0) |

## Users

* `func_80091CC0` — clears the register and installs the DMA interrupt handler
  at IRQ 3.
* `func_80091D0C` — the handler: reads the channel flags, acknowledges one
  channel, and dumps the register through `func_8008E000` if no valid source is
  pending.
* `func_80091E8C` — read-modify-write: `tmp = *gDmaInterruptCtrlPtr & 0xFFFFFF;
  *gDmaInterruptCtrlPtr = tmp | bits;` to enable channels.

`analysis/refs.json` lists 7 references to the slot in 3 functions, all 4-byte
loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
u32 pending = (*gDmaInterruptCtrlPtr >> 24) & 0x7F;  /* reads DICR flags */
u32 addr = (u32)gDmaInterruptCtrlPtr;                /* 0x1F8010F4, no effect */
```

## C integration status

Renamed from `D_8009DD60` to `gDmaInterruptCtrlPtr` in the three C users; the
retail symbol is kept with `__asm__("D_8009DD60")`. No object is defined, the
retail word stays in `asm/us/main.s`, and all three units still compile to the
exact retail bytes (SHA-256 compared before and after the rename).
