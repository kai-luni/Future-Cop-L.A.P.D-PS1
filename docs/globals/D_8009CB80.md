# D_8009CB80 — second SPU register block pointer

## Identity

| item | value |
| --- | --- |
| retail symbol | `D_8009CB80` |
| C name | `gSpuRegsAltPtr` |
| slot address | `0x8009CB80` (4 bytes, writable, inside the payload's `.text`) |
| initial value | `0x1F801C00` |
| points at | SPU register block (voice 0 base), second retail pointer |
| assembler label | `SPU_REGS_ALT_ASM` in `include/game/spu_globals.h` |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009CB80
    /* 8D380 8009CB80 001C801F */ .word 0x1F801C00
```

File offset `0x8D380` of `SLUS_007.39` holds `00 1C 80 1F`, i.e. `0x1F801C00` —
the same address as `gSpuRegBasePtr`, but a different retail variable.

## Hardware meaning

The unit in `func_8008F7AC` declares a struct with `pad[0x180]` and then fields
for the global SPU registers. Its writes land on:

| field | offset | register |
| --- | --- | --- |
| `a`, `b` | `0x180`, `0x182` | main volume left / right |
| `c` | `0x1AA` | SPUCNT control |
| `d`, `e` | `0x1B0`, `0x1B2` | reverb volume left / right |
| `f`, `g` | `0x1B8`, `0x1BA` | unused / reserved area |

The unit sets both volume pairs to `0x3FFF` (maximum) and the control word to
`0xC001` — an unmute/setup step at CD-ROM initialisation. The pointer is the
same block as `gSpuRegBasePtr`; the name marks it as the alternate pointer so the
two retail variables stay distinguishable.

## Correct C type

`struct State *` — a local view with the `0x180` prefix and halfword fields.

## Users

* `func_8008F7AC` — sets the volumes and the control word while initialising the
  CD/SPU path.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
gSpuRegsAltPtr->a = 0x3FFF;        /* main volume left  (0x1F801D80) */
gSpuRegsAltPtr->c = 0xC001;        /* SPUCNT control    (0x1F801DAA) */
u32 base = (u32)gSpuRegsAltPtr;    /* 0x1F801C00, no effect          */
```

## C integration status

Renamed from `D_8009CB80` to `gSpuRegsAltPtr` in its single user; the retail
symbol is kept with `__asm__("D_8009CB80")`. No object is defined, the retail
word stays in `asm/us/main.s`, and the unit still compiles to the exact retail
bytes (SHA-256 compared before and after the rename).
