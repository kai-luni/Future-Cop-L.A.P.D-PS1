## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009EEA8
    /* 8F6A8 8009EEA8 C010801F */ .word 0x1F8010C0
```

File offset `0x8F6A8` of `SLUS_007.39` holds `C0 10 80 1F`, i.e. `0x1F8010C0`.
The next two slots are the block control (`0x1F8010C4`) and the channel control
(`0x1F8010C8`) of the same channel.

## Hardware meaning

`0x1F8010C0` is `DMA4_MADR`, the memory address register of DMA channel 4, the
SPU channel. `func_800973B4` stores the caller's buffer pointer here as the
first step of an SPU transfer, followed by the block control word and
`0x01000200` in the channel control register.
