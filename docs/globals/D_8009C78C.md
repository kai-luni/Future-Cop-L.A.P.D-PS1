## Hardware meaning

`0x1F801040` is `JOY_DATA`, the data register of serial port 0 (controller and
memory card). The neighbouring words are the rest of the block:

| offset | register | purpose |
| --- | --- | --- |
| `0x0` | JOY_DATA | transmit/receive data |
| `0x4` | JOY_STAT | status (bit 7 = interrupt, bit 1 = receive FIFO not empty) |
| `0xA` | JOY_CTRL | control (bit 4 = acknowledge, bit 6 = reset) |
| `0xE` | JOY_BAUD | baud rate |

The units use the pointer as the base of that block: a struct (`Port`,
`Device`, `State`, `StatusState`), a byte offset (`+4`, `+0xA`) or an index
(`[7]`). Register numbering and bit meanings follow public PlayStation
documentation.

## Correct C type

`volatile u8 *` — the data register is byte wide, and the pointer is the base of
a register block, so units that need a wider view re-type it per access.

| unit | declaration |
| --- | --- |
| `func_8008ADB4` | `u8 *` |
| `func_8008A43C` | `short *` |
| `func_8008A6CC`, `func_8008AB80`, `func_8008AE44` | pointer to a local struct (`State`, `Device`, `StatusState`) |
| `func_8008A9A8` | `Port *` |

## Users

* `func_8008A43C` — writes the baud rate (`0x88` at offset `0xE`).
* `func_8008A6CC` — sets the control bits (`flags`) and reads the port state.
* `func_8008A9A8` — pad transfer loop: reads `data`, polls `status`, drives
  acknowledge.
* `func_8008AB80` — writes the transmit word and polls the status bit `0x80`.
* `func_8008ADB4` — checks `JOY_STAT` bit 7 through `+4`, sets `JOY_CTRL` bit 4
  through `+0xA`.
* `func_8008AE44` — waits for status bit 1 (receive FIFO not empty).

`analysis/refs.json` lists 18 references to the slot in 6 functions, all 4-byte
loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
gSio0RegBasePtr->data = value;                    /* writes JOY_DATA        */
if (*(volatile u16 *)(gSio0RegBasePtr + 4) & 0x80) /* reads JOY_STAT        */
u32 addr = (u32)gSio0RegBasePtr;                  /* 0x1F801040, no effect  */
```

## C integration status

symbol is kept with `__asm__("D_8009C78C")`. No object is defined, the retail
word stays in `asm/us/main.s`, and all six units still compile to the exact
retail bytes (SHA-256 compared before and after the rename).
