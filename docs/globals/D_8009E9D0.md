## Hardware meaning

`0x1F801094` is `DMA1_BCR`, the block control register of DMA channel 1: low
half = block size in words, high half = block count. The unit writes
`((size >> 5) << 16) | 0x20`, the same 32-word block layout the MDEC output path
uses.
