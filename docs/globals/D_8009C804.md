## Hardware meaning

`func_8008DA14` declares `struct { char pad[10]; volatile short value; }` over
the pointer and clears `->value`, i.e. `0x1F80104A` (`JOY_CTRL`), followed by a
busy wait. The role is the same as `gSio0CtrlPtr`; retail keeps two separate
pointer variables for the two call sites, and the names differ only to keep them
distinct.

## Correct C type

`0x1F80104A`.
