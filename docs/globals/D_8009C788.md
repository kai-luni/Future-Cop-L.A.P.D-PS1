## Hardware meaning

`0x1F801070` is `I_STAT`, the interrupt status and acknowledge register. Each
bit stands for one source (bit 0 VBLANK, 1 GPU, 2 CD-ROM, 3 DMA, 4–6 timers,
7 controller/memory card, …). **Writing 0 to a bit acknowledges that
interrupt**; writing 1 leaves it untouched. That is why the game writes
`-0x2` (`0xFFFFFFFE`, clears bit 0 only) and `-0x81` (`0xFFFFFF7F`, clears bit 7
only) instead of a plain zero.

Bits this game tests: `0x80` (bit 7) in the pad polling loops of
`func_8008A9A8`, `func_8008AB80` and `func_8008ADB4`; bit 0 in
`func_8008A3D4`. Bit numbering follows public PlayStation documentation.

The mask register `0x1F801074` is the next word, so `func_8008A3D4` models both
as a two-word struct (`Flags.first` = I_STAT, `Flags.second` = I_MASK) through
this one pointer.

## Correct C type

`volatile u32 *` — pointer to a volatile 32-bit register with write-to-clear
semantics.

| unit | declaration |
| --- | --- |
| `func_8008A9A8`, `func_8008AB80` | `volatile u32 *` |
| `func_8008A5BC`, `func_8008A6CC` | `s32 *` |
| `func_8008ADB4` | `u32 *` |
| `func_8008A3D4` | `Flags *` (two-word struct, I_STAT + I_MASK) |

## Users

* `func_8008A3D4` — tests bit 0 in both words of the struct.
* `func_8008A5BC` — acknowledges and unmasks the pad interrupt, writes
  `0xFFFFFFFE`.
* `func_8008A6CC` — writes `-0x81` (`0xFFFFFF7F`) to clear the pad interrupt.
* `func_8008A9A8`, `func_8008AB80` — poll `& 0x80` while waiting for the pad.
* `func_8008ADB4` — writes `0xFFFFFF7F` and polls the port status.

`analysis/refs.json` lists 7 references to the slot in 6 functions, all 4-byte
loads; the slot itself is never written.

Uncertainty: the doc comment in `src/game/8008ADB4.c` calls this global "the
counter". The retail value `0x1F801070` and the write-to-clear pattern show it
is I_STAT; the comment is inaccurate and was left untouched by the rename.

## Accessing the variable vs. the register

```c
while (!(*gInterruptStatusPtr & 0x80)) { }  /* polls I_STAT                  */
*gInterruptStatusPtr = 0xFFFFFF7F;          /* clears bit 7, keeps the rest  */
u32 addr = (u32)gInterruptStatusPtr;        /* 0x1F801070, no side effect    */
```

## C integration status

Renamed from `D_8009C788` to `gInterruptStatusPtr` in the six C users; the
retail symbol is kept with `__asm__("D_8009C788")`. No object is defined, the
retail word stays in `asm/us/main.s`, and all six units still compile to the
exact retail bytes (SHA-256 compared before and after the rename).
