# D_8009DD84 — DMA channel register block pointer

## Identity

| item | value |
| --- | --- |
| retail symbol | `D_8009DD84` |
| C name | `gDmaChannelRegBasePtr` |
| slot address | `0x8009DD84` (4 bytes, writable, inside the payload's `.text`) |
| initial value | `0x1F801080` |
| points at | DMA channel 0 address register, base of the per-channel register block |
| assembler label | `DMA_CHANNEL_BASE_ASM` in `include/game/dma_globals.h` |

## Retail evidence

`asm/us/main.s`:

```

    /* 8E584 8009DD84 8010801F */ .word 0x1F801080
```

File offset `0x8E584` of `SLUS_007.39` holds `80 10 80 1F`, i.e. `0x1F801080`.

Load in `func_80091D0C`:

```
    /* 82640 80091E40 0A80023C */  lui        $v0, %hi(D_8009DD84)
    /* 82644 80091E44 84DD428C */  lw         $v0, %lo(D_8009DD84)($v0)
```

## Hardware meaning

`0x1F801080` is `DMA0_MADR`. The interrupt handler indexes it as an array of
four-word channel descriptors — `D_8009DD84[channel].madr` — which matches the
layout of the DMA block (address, block control, channel control, unused, per
channel). The register numbers follow public PlayStation documentation.

## Correct C type

`DmaChannel *` — a pointer to a local struct that mirrors one channel's four
words. Only this unit uses the symbol.

## Users

* `func_80091D0C` — the DMA interrupt handler: for each pending channel it
  reads `[channel].madr` and passes it to the diagnostic logger
  `func_8008E000` when the status is unexpected.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
u32 address = gDmaChannelRegBasePtr[channel].madr;  /* reads DMA0_MADR */
u32 base = (u32)gDmaChannelRegBasePtr;              /* 0x1F801080      */
```

## C integration status

Renamed from `D_8009DD84` to `gDmaChannelRegBasePtr` in its single user; the
retail symbol is kept with `__asm__("D_8009DD84")`. No object is defined, the
retail word stays in `asm/us/main.s`, and the unit still compiles to the exact
retail bytes (SHA-256 compared before and after the rename).
