```
    /* 80454 8008FC54 A0CB428C */  lw         $v0, %lo(D_8009CBA0)($v0)
```

## Hardware meaning

`0x1F801018` is the CD-ROM delay register: memory access timing for the CD-ROM
register area. The sector-read paths write two configurations, `0x20943` and
`0x21020843`, before they touch the CD ports and DMA channel 3. The register
number follows public PlayStation documentation; the game's code shows only the
two constants, not their field meaning.

## Correct C type

`volatile u32 *` in both users.

## Users

* `func_8008FC30` — writes `0x20943` before starting a sector transfer.
* `func_8008FD30` — writes `0x21020843` in the same path.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
*gCdromAccessDelayPtr = 0x20943;        /* programs the timing */
u32 addr = (u32)gCdromAccessDelayPtr;   /* 0x1F801018          */
```

## C integration status

Renamed from `D_8009CBA0` to `gCdromAccessDelayPtr` in its two C users; the
retail symbol is kept with `__asm__("D_8009CBA0")`. No object is defined, the
retail word stays in `asm/us/main.s`, and both units still compile to the exact
retail bytes (SHA-256 compared before and after the rename).
