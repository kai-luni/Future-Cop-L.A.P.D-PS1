## Retail evidence

```
dlabel D_8009C808
    /* 8D008 8009C808 7010801F */ .word 0x1F801070
```

File offset `0x8D008` of `SLUS_007.39` holds `70 10 80 1F`, i.e. `0x1F801070`.

## Hardware meaning

`0x1F801070` is `I_STAT`. This unit models the status and mask pair as a struct
with `current` and a second word and tests `current & 1`, i.e. the VBLANK
source. Two further retail pointers hold the same address
(`gInterruptStatusPtr`, `gInterruptStatusHalfPtr`); the names stay distinct
because retail keeps three separate variables with three different types.

## Correct C type

`InputState *` — a local struct with the status word first.

## Users

* `func_8008DA7C` — checks the VBLANK bit of the status word.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
if (gInterruptStatusStatePtr->current & 1) { }  /* reads I_STAT bit 0 */
u32 addr = (u32)gInterruptStatusStatePtr;       /* 0x1F801070         */
```

retail symbol is kept with `__asm__("D_8009C808")`. No object is defined, the
retail word stays in `asm/us/main.s`, and the unit still compiles to the exact
