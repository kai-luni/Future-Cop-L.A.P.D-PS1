## Retail evidence

```
    /* 8F1F0 8009E9F0 2018801F */ .word 0x1F801820
```

File offset `0x8F1F0` of `SLUS_007.39` holds `20 18 80 1F`, i.e. `0x1F801820`.
The next slot `D_8009E9F4` (`0x1F801824`) is the control/status word.

## Hardware meaning

`0x1F801820` is the MDEC command port: writing here submits a decoder command
or one of its parameter words. `func_80096240` copies the caller's header word
(which carries the command number) into it before enabling the DMA channels and
programming the transfer.

## Correct C type

`u32 *`.

## Users

* `func_80096240` — writes the command/header word `*arg0`.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
*gMdecCommandPtr = header;        /* submits a command or parameter */
u32 addr = (u32)gMdecCommandPtr;  /* 0x1F801820                     */
```
