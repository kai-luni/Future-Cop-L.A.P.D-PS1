# D_8009CBA8 — DMA channel 3 memory address pointer

## Identity

| item | value |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009CBA8
    /* 8D3A8 8009CBA8 B010801F */ .word 0x1F8010B0
```

File offset `0x8D3A8` of `SLUS_007.39` holds `B0 10 80 1F`, i.e. `0x1F8010B0`.
The two following slots are the block control (`0x1F8010B4`) and the channel
control (`0x1F8010B8`) of the same channel.

## Hardware meaning

`0x1F8010B0` is `DMA3_MADR`, the memory address register of DMA channel 3, the
CD-ROM channel. Both sector-read units store the destination buffer pointer here
before programming the block and channel control registers.

## Correct C type

`volatile u32 *` in both users.

## Users

* `func_8008FC30` — `*ptr = destination` before starting a sector transfer.
* `func_8008FD30` — same address programming in the variant path.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
*gDma3MemAddrPtr = (u32)dest;     /* programs MADR3 */
u32 addr = (u32)gDma3MemAddrPtr;  /* 0x1F8010B0     */
```
