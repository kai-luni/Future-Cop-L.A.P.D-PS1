# D_8009DD54 — timer 1 mode pointer

## Identity

| item | value |
| --- | --- |
| retail symbol | `D_8009DD54` |
| C name | `gTimer1ModePtr` |
| slot address | `0x8009DD54` (4 bytes, writable, inside the payload's `.text`) |
| initial value | `0x1F801114` |
| points at | root counter 1 mode register |
| assembler label | `TIMER1_MODE_ASM` in `include/game/timer_globals.h` |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009DD54
    /* 8E554 8009DD54 1411801F */ .word 0x1F801114
```

File offset `0x8E554` of `SLUS_007.39` holds `14 11 80 1F`, i.e. `0x1F801114`,
the mode register of root counter 1.

## Hardware meaning

`0x1F801114` is the mode register of root counter 1: clock source, gate,
interrupt target and reset behaviour. `func_80091BA0` writes `0x107` during
VSync interrupt setup, which selects the timer configuration used for the frame
counter. The exact field split of `0x107` is not proven here; only the written
value is measured.

## Correct C type

`s32 *` — the single user was matched with a signed 32-bit pointer.

## Users

* `func_80091BA0` — writes `0x107` and installs the VSync handler on IRQ 0.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
*gTimer1ModePtr = 0x107;          /* programs the timer mode */
u32 addr = (u32)gTimer1ModePtr;   /* 0x1F801114              */
```

## C integration status

Renamed from `D_8009DD54` to `gTimer1ModePtr` in its single user; the retail
symbol is kept with `__asm__("D_8009DD54")`. No object is defined, the retail
word stays in `asm/us/main.s`, and the unit still compiles to the exact retail
bytes (SHA-256 compared before and after the rename).
