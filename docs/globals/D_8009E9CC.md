## Hardware meaning

`0x1F801090` is `DMA1_MADR`, the memory address register of DMA channel 1 (the
MDEC input channel). The unit stores the destination buffer pointer here before
programming the block control and the channel control (`0x01000200`).

## Correct C type

`u32 *`.

## Users

