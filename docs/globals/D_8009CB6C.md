# D_8009CB6C — CD-ROM index/status pointer

## Identity

| item | value |
| --- | --- |
| retail symbol | `D_8009CB6C` |
| C name | `gCdromIndexStatusPtr` |
| slot address | `0x8009CB6C` (4 bytes, writable, inside the payload's `.text`) |
| initial value | `0x1F801800` |
| points at | CD-ROM index/status register (bank select on write, status on read) |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009CB6C
    /* 8D36C 8009CB6C 0018801F */ .word 0x1F801800
```

File offset `0x8D36C` of `SLUS_007.39` holds `00 18 80 1F`, i.e. `0x1F801800`.
The next slots (`D_8009CB70` → `0x1F801801`, `D_8009CB74` → `0x1F801802`,
`D_8009CB78` → `0x1F801803`) point at the other three CD-ROM ports; they are
separate globals and are not renamed here.

Bank select in `func_8008E7A0`:

```

    /* 7EFA8 8008E7A8 6CCB638C */  lw         $v1, %lo(D_8009CB6C)($v1)
    /* 7EFAC 8008E7AC 01000224 */  addiu      $v0, $zero, 0x1
```

## Hardware meaning

`0x1F801800` is the CD-ROM index/status register:

* **write** — bits 0–1 select the register bank; the meaning of the other three
  port addresses depends on the bank
* **read** — the low bits report the interrupt enable/flag state of the
  selected bank

That dual role is why the driver saves the value, switches the bank, and
restores it (`func_8008ECFC`, `func_8008EF7C`, `func_8008F244` all keep the old
value in a register across the sequence). The game also writes `1` and `0`
directly to select bank 1 / bank 0 and spins on bit `0x20`. Register layout
follows public PlayStation documentation.

`func_8008E5B8` mentions the symbol only in a doc comment and stays unchanged.

## Users

11 functions reference the slot (`analysis/refs.json`: 27 references, all
4-byte loads; the slot itself is never written). Main paths:

* `func_8008E7A0` — bank selection around a command, polls bit `0x20`.
* `func_8008ECFC`, `func_8008EF7C`, `func_8008F244` — save the port value,
  run the command sequence, restore it.
* `func_8008F650` — selects the bank before reading the result ports.
* `func_8008F6D8`, `func_8008F7AC`, `func_8008F8E8` — command dispatch.
* `func_8008FC30`, `func_8008FD30`, `func_8008FE28` — sector reads combined
  with DMA3.

## Accessing the variable vs. the register

```c
*gCdromIndexStatusPtr = 1;                       /* selects bank 1        */
while (!(*gCdromIndexStatusPtr & 0x20)) { }      /* polls the status bit */
u32 addr = (u32)gCdromIndexStatusPtr;            /* 0x1F801800, no effect */
```

## C integration status

Renamed from `D_8009CB6C` to `gCdromIndexStatusPtr` in its eleven C users; the
retail symbol is kept with `__asm__("D_8009CB6C")`. No object is defined, the
retail word stays in `asm/us/main.s`, and all twelve units that mention the
symbol still compile to the exact retail bytes (SHA-256 compared before and
after the rename).
