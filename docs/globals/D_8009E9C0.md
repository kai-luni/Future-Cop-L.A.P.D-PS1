## Hardware meaning

`0x1F801080` is `DMA0_MADR`, the memory address register of DMA channel 0 (the
MDEC output channel). `func_80096240` stores `arg0 + 1` here, i.e. the source
address one byte past the caller's pointer, before programming the block
control and channel control registers.

Uncertainty: the doc comment in `src/game/80096240.c` calls the group "likely DMA
channel 4". The address `0x1F801080` is channel 0 in the public register map and
the neighbouring units program channel 0 as MDEC output, so the comment is
inaccurate; it was left untouched by the rename.
