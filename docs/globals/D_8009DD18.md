# D_8009DD18 — interrupt mask pointer

## Identity

| item | value |
| --- | --- |
| retail symbol | `D_8009DD18` |
| C name | `gInterruptMaskPtr` |
| slot address | `0x8009DD18` (4 bytes, writable, inside the payload's `.text`) |
| initial value | `0x1F801074` |
| points at | interrupt mask register (I_MASK) |
| assembler label | `INT_MASK_ASM` in `include/game/intc_globals.h` |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009DD18
    /* 8E518 8009DD18 7410801F */ .word 0x1F801074
```

File offset `0x8E518` of `SLUS_007.39` holds `74 10 80 1F`, i.e. `0x1F801074`.
The slot follows `D_8009DD14` (`0x1F801070`, the interrupt status slot) in the
same pointer block.

Halfword read in `func_800915E4`:

```
    /* 81DE4 800915E4 0A80023C */  lui        $v0, %hi(D_8009DD18)
    /* 81DE8 800915E8 18DD428C */  lw         $v0, %lo(D_8009DD18)($v0)
    /* 81DEC 800915EC 00000000 */  nop
    /* 81DF0 800915F0 00004294 */  lhu        $v0, 0x0($v0)
```

The `lhu` is why most units declare the pointer as `u16 *`: the game only uses
the low halfword of the register.

## Hardware meaning

`0x1F801074` is `I_MASK`, the interrupt mask. Bit *n* enables source *n* of
I_STAT (0 VBLANK, 1 GPU, 2 CD-ROM, 3 DMA, 4–6 timers, 7 controller/memory
card, …). The register is 16 bits wide in the game's usage, although the
hardware implements the low 11 bits. Bit numbering follows public PlayStation
documentation.

## Correct C type

`volatile u16 *` — pointer to a volatile 16-bit register. Units that only
compute pointer values use a non-volatile form.

| unit | declaration |
| --- | --- |
| `func_80091614`, `func_80091A04` | `volatile u16 *` |
| `func_800918BC` | `volatile short *` |
| `func_800915E4`, `func_800915FC`, `func_800916EC`, `func_80091AA4` | `u16 *` |

## Users

* `func_800915E4` — returns the current mask.
* `func_800915FC` — swaps the mask: reads the old value, writes the new one,
  returns the old mask so callers can restore it.
* `func_80091614` — initialisation, publishes the mask pointer next to
  `D_8009DD14`.
* `func_800916EC` — loop `while (pending = D_8009CCB8 & *D_8009DD14 & *gInterruptMaskPtr)`:
  combines status and mask to wait for enabled interrupts.
* `func_800918BC` — writes the mask bits computed from a table.
* `func_80091A04` — pointer bookkeeping during IRQ setup.
* `func_80091AA4` — writes `ctx->value` during a register dump/restore.

`analysis/refs.json` lists 10 references to the slot in 7 functions, all 4-byte
loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
u16 old = *gInterruptMaskPtr;   /* reads I_MASK                  */
*gInterruptMaskPtr = bits;      /* programs the mask             */
u32 addr = (u32)gInterruptMaskPtr;  /* 0x1F801074, no side effect */
```

## C integration status

Renamed from `D_8009DD18` to `gInterruptMaskPtr` in the seven C users; the
retail symbol is kept with `__asm__("D_8009DD18")`. No object is defined, the
retail word stays in `asm/us/main.s`, and all seven units still compile to the
exact retail bytes (SHA-256 compared before and after the rename).
