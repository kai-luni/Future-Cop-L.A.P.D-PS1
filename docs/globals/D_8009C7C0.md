# D_8009C7C0 — serial port 0 control pointer

## Identity

| item | value |
| --- | --- |

## Retail evidence

`asm/us/main.s`:

```
dlabel D_8009C7C0
    /* 8CFC0 8009C7C0 4010801F */ .word 0x1F801040
```

File offset `0x8CFC0` of `SLUS_007.39` holds `40 10 80 1F`, i.e. `0x1F801040`.

## Hardware meaning

The unit declares `struct H { char pad[10]; u16 v; }` over the pointer and
writes `->v`, i.e. `0x1F801040 + 0xA = 0x1F80104A`, which is `JOY_CTRL`. A store
of 0 there resets the port (clears the acknowledge and transfer bits). The name
therefore describes the register the unit writes, not the word the pointer
literally holds.

## Correct C type

`struct H *` — a local two-field view whose second field lands on JOY_CTRL.

## Users

* `func_8008BF78` — clears the control word on each iteration of a pad retry
  loop.

`analysis/refs.json` records the slot loads; the slot itself is never written.

## Accessing the variable vs. the register

```c
gSio0CtrlPtr->v = 0;            /* writes JOY_CTRL (0x1F80104A) */
u32 base = (u32)gSio0CtrlPtr;   /* 0x1F801040, no effect        */
```
