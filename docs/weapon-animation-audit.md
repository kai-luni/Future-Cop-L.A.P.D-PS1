# Weapon animation area - audit

Investigation of the per-frame weapon slot, beam-part and projectile code
(`src/game/80055E10.c`, `8006BA50.c`, `8006ACB0.c`, `8006B23C.c`, the `8006BD*`
refill trio and the `8005E*` spawners). Every finding cites the file and line it
was checked against.

Status: the three findings that were verified against the body and the retail asm
have been fixed in place (the `+0x310` pause byte in `80055E10.c`, the per-slot
`+0x8A` counter and the caller frequency in `8006BA50.c`). The remaining entries
are still open - treat them as leads, not as contract.

### 1. Documentation defects

Ordered by impact on callers, data layout, and control flow.

1. **`src/game/80055E10.c:34` — Wrong input-lock offset.** The comment puts `locked` at control `+0x2C8`. The retail entry at `0x80055E10` loads a signed byte from control `+0x310` and returns when it is nonzero. The C layout and the pause toggle agree. `src/game/80055E10.c:9–20,60–63`, `asm/us/main.s:81832–81843`, `src/game/80027510.c:185–197`.

2. **`src/game/8006BDFC.c:59–60` — Wrong callers.** The named loadout reset and weapon update loop do not call this unit. The retail direct calls are in the pickup/supply routine and the cheat dispatcher. The loadout reset initializes the arrays itself, and the weapon update has its own swap branch. `asm/us/main.s:38093,94276,94285,94294`, `src/game/8002FC90.c:194–200`, `src/game/80060A0C.c:153–164`, `src/game/8006AB38.c:76–108`, `src/game/8006BA50.c:211–217`.

3. **`src/game/8006BA50.c:82–84,93–95,101–114` — `+0x8A` is described as a shared counter.** It is an array of three signed halfwords, read and written at `+0x8A + 2*idx`. The same indexing selects the definition and muzzle parity in both dispatch paths. The claim that `D_8009FA8C` selects single versus paired fire is also unsupported. Its nonzero state causes XOR with `1`, gates player damage, and can be set by the cheat dispatcher. `src/game/8006BA50.c:19–25,60–68,172–185,192–213`, `src/game/8006ACB0.c:123–133,153–157`, `src/game/8006B23C.c:237–249`, `src/game/80058210.c:85–102`, `src/game/80060A0C.c:135–138`.

4. **`src/game/8006BA50.c:106–108` and `src/game/8006BDFC.c:36–42,56–57` — Registry references mislabeled as muzzle halves or range values.** The loader resolves four resource references into the pointer array at record `+0x44..+0x50`. Both units swap its first and fourth words. The fire dispatcher reads the current `+0x44` reference for projectile setup and selects the muzzle separately from control `+0x178` and counter parity. The refill copies record `+0x2A` **into control `+0x93+idx`**. It leaves record `+0x2A` untouched. `src/game/8006A918.c:29–34,88–100`, `src/game/8006BA50.c:211–217`, `src/game/8006BDFC.c:64–77`, `src/game/8006ACB0.c:123–133,223–232,236–264`.

5. **`src/game/8006BA50.c:76–78,120–121` — Call frequency and slot-2 trigger are wrong.** The caller can dispatch zero to three slots per poll. Slots 0 and 1 are independent held-bit tests. Slot 2 compares the decoded phase with control `+0xA5`, which actor reset sets to held phase `3` and loadout reset can set to press phase `0`. The statement that the caller always calls all three slots and that slot 2 is edge-only is therefore false. `src/game/80055E10.c:60–79`, `src/game/800573A4.c:252–257`, `src/game/8006AB38.c:100–105`, `src/game/8005780C.c:43–55`.

6. **`src/game/8005EE04.c:94` — The C declaration hides the retail return contract.** The unit is declared `void`, but its retail epilogue preserves `$v0` from `func_8004D444`. Both fire dispatchers consume that register as the spawned-entity result. A caller relying on the doc block would miss the return value used for pending-entity bookkeeping and secondary effects. `src/game/8005EE04.c:75–80,179–190`, `src/game/8004D444.c:49–60`, `asm/us/main.s:92249–92260,92799–92802,105901–105904`, `src/game/8006ACB0.c:280–295`, `src/game/8005F6E8.c:431–441`.

7. **`src/game/8006ACB0.c:69,86–89` — Incomplete return and tail contract.** Action `0xD` returns the low byte of `func_8005D690`, which can be zero even after the capacity gate passes. Actions `0xF`, `0x11`, and `0xD` bypass the tail. The remaining paths save a non-null result and its id at `+0x98/+0x9C` only when `def[1] & 4` is set. The secondary spawn requires `def[0x1B] != 0`. Its fallback uses a second transform from `owner->unkDC + 0x28` and a C local of size `0x50`; the retail `0x60` is the local’s stack offset. `src/game/8006ACB0.c:22–40,116–119,267–300`, `src/game/8005D690.c:59–61,94–99`, `asm/us/main.s:105981–106014`.

8. **`src/game/8006B23C.c:159,183–194,202–203` — The callback and effect dispatch contract is misleading.** `arg2` is a definition byte from `entry+0x1F`, forwarded into `cb.unk06`; the caller supplies slot indices `0..2`. The callback runs **before** visual dispatch, never for type `0x0E`, and requires a clear ray and a non-null `c`. During the positive secondary-counter and positive-radius path, it also requires the `c->unk24` mask for every eligible type. Chain arcs run only for type `0x0B` with the positive secondary-counter flag. The first effect uses column `s3->unk1A` when `fp` and that byte are both nonzero. `5` is a payload byte at `local+0x49`, not the column. `src/game/8006BA50.c:140,184–190`, `src/game/8006B23C.c:98–104,345–437`.

9. **`src/game/8005D690.c:18,32–34` — The high-value clamp and bit-2 updates are misstated.** In either parameter copy, `high = low * 8 / 5` runs only when the supplied `high < low`. For example, `(low, high) = (10, 11)` stays `(10, 11)`. Bit 2 is assigned in opposite directions in the effect entry and its referenced object based on the indexed signed halfword. Repeating the same update leaves those bits in the same state. The allocator stores the dome-mesh pointer returned by `func_8006C84C` at entry `+0x00`. `src/game/8005D690.c:59–97`, `src/game/8005D3FC.c:108–150`.

10. **`src/game/8005F6E8.c:127–128,133–151` — Several dispatch rules change observable results.** Output flag bit `1` is set when input flag `0x400` is **clear**. Type 8 takes its early spawn path only when actor `+0x84` is nonzero. Type 2 with no target uses the actor’s facing vector. With flag `0x800`, a dot product equal to `0xF22F` fails. A zero low byte of `a3` can reach the sound-only success path and return `1`, or fail a prior gate and return `0` silently. The success tail decrements only nonnegative ammo, and the failure tail mutates cooldown fields only when `a3` has a nonzero low byte. `src/game/8005F6E8.c:186–214,227–257,302–319,396–429,451–462`.

11. **`src/game/8006BE90.c:25–31,35–36` — “Clamped” and “was increased” overstate the guarantee.** A below-limit counter with `step == 0` returns `0` without increasing. For a positive step, the addition is stored as a signed halfword before the comparison. For example, `32000 + 1000` narrows to `-32536`, which passes the upper-bound check for a limit of `32767`. `src/game/8006BE90.c:4–9,46–61`, `asm/us/main.s:106936–106954`.

12. **`src/game/8005E9E4.c:35–36,42–45` — Wrong muzzle-height indirection and unclear flag source.** The offset comes from a signed halfword at `+0x14` in the object reached through the owner’s `+0x34` pointer. The caller’s `pos->y` is updated in place before copying the position and calling the solver. The `0x100` bit in the request follows `ent+0x24`; the body explicitly clears an incoming `0x100` when that entity bit is clear. `src/game/8005E9E4.c:14–15,77–89,101–114`, `asm/us/main.s:91913–91932`.

13. **`src/game/8005E47C.c:34,42–45`, `src/game/8005EB74.c:83,91`, and `src/game/8005EE04.c:87,97–102` — Projectile operand descriptions obscure the actual fields.** In the direct spawner `a3` is the launch-vector address supplied by both dispatchers, and `a5` is the pointer whose presence sets request `+0x30`. All three spawners explicitly clear request `+0x14` bit `0x100` when `ent+0x24` lacks that bit. The jitter unit’s `obj+0x02` and `+0x0A` populate request `+0x38` and `+0x34`; the fallback velocity scale comes from `obj+0x06`, and the jitter base comes from `obj+0x0C`. `src/game/8005E47C.c:85–111`, `src/game/8006ACB0.c:223–232`, `src/game/8005F6E8.c:405–416`, `src/game/8005EB74.c:115–140`, `src/game/8005EE04.c:150–186`.

14. **`src/game/8005E2A0.c:17–25,30–40` — The lead solver reverses the practical roles of its points.** Weapon callers pass the muzzle first, then the tracked object’s position and motion as the fifth and sixth arguments. The function advances the tracked position along that motion and measures each predicted point against the muzzle. The iteration budget is one step when `(scale << 4) < arg2`, otherwise up to nine. `src/game/8005E2A0.c:62–103`, `src/game/8006ACB0.c:198–204`, `src/game/8005F6E8.c:245–256`, `src/game/8005CBCC.c:206–217`.

15. **`src/game/8005E624.c:25–26,40–47` — The arithmetic summary overpromises and describes unreachable branches.** `angle*300` is an internal scale followed by fixed-point truncation and planar rescaling, so exact output magnitude is unsupported. The `len < 2` clamp makes both later `len <= 0` arms unreachable. The code halves `q` with a shift and `d` with `/ 2`; “every quotient” is too broad. The discriminant helper is the GTE-backed square-root lookup. `src/game/8005E624.c:102–154,181–195`, `src/game/80095900.c:45–84`.

16. **`src/game/8006C488.c:19–21,35–36` — “Alert,” “damaged variant,” and voice stopping are unsupported.** The wrapper chooses sound id `0x33` or `0x32` from the sign of one counter. Its callee refreshes a matching handle, clears a stale slot’s status, or tries to start a voice. There is no voice-stop or retune operation in this path, and the selection does not read a damage field. `src/game/8006C488.c:41–49`, `src/game/80046CF0.c:76–115`.

### 2. Documentation gaps

1. **Reload and cycle timing.** `func_800588D4` calls `func_8006C3E0` before polling weapons. It subtracts elapsed ticks from all three positive `+0x78` timers and clamps at zero. The slot driver then adds the selected signed delay. Its `u8` cycle counter wraps `0 → 255`, so only a pre-decrement value of `1` selects the cycle reload and `entry+0x08` delay. Secondary depletion can overwrite that cycle reload with record `+0x0A` while keeping the delay already added. `src/game/800588D4.c:287–291`, `src/game/8006C3E0.c:60–70`, `src/game/8006BA50.c:41–46,169–173,205–217`, `asm/us/main.s:106755–106795`.

2. **Beam contact and radial damage.** The positive secondary-counter path uses radius `entry+0x0E << 4` for radial damage only when that signed field is positive, the ray’s low byte is zero, and type differs from `0x0E`. The center is `c+0x50` when an anchor exists and the computed endpoint otherwise. The random-placement path can set `fp` before tracing, so a clear ray can still produce the `+0x1A` effect. `src/game/8006B23C.c:271–300,345–385,417–437`.

3. **Input record setup and sampling.** Actor reset sets the fire, special, and weapon masks at `+0x34/+0x3C/+0x4C` to `0x00800000/0x02000000/0x01000000`, and their phases to idle `2`. The slot-0 and slot-1 masks are separate. The poller snapshots `+0x30` for those two slots while reloading it for the fire and weapon decodes. `src/game/800573A4.c:237–262`, `src/game/80055E10.c:64–78`, `src/game/8005780C.c:43–55`.

4. **Dome entry ownership and deadlines.** Allocation can occur per weapon slot during loadout. Update searches by owner alone and uses the first matching entry’s stored `+0x54` index, or requests index `0` on a miss. For a player with extra parameters, equality with the deadline preserves bit 0, and every call extends the deadline by `60`. The fallback writes `now+120` and sets bit 0. `src/game/8006AB38.c:100–108`, `src/game/8005D3FC.c:139–155`, `src/game/8005D690.c:53–97`.

5. **Refill index preconditions.** The two refill bodies use unguarded indexing into three-slot layouts and immediately use the registry result. `gRegistryFind` can return null. The pickup caller walks four mask positions for each refill, so a set fourth bit can mechanically supply index `3`. The cited bodies leave the validity of that input unresolved. `src/game/8006BDFC.c:4–11,30–31,62–77`, `src/game/8006BE90.c:4–9,44–58`, `src/game/8006AAEC.c:32–42`, `src/game/8002FC90.c:184–200`.

6. **Entity-table headroom.** The player fire gate compares the active count at `D_800A8F90+0` with the configured limit at `+4`, requiring a difference of at least `10`. Initialization selects `0xFE`, `0x12C`, or `0xC8` using session fields. Those words describe table headroom. The spawn allocator is a separate call. `src/game/8006ACB0.c:42,116–119`, `src/game/8004CAE4.c:66–73,109–122`, `src/game/8004D444.c:49–60`.

7. **Player action 8 depends on inherited velocity.** It passes `&locals.vec` without assigning it on that action path. `func_8005EE04` with flag zero avoids reading that vector if the firing entity has nonzero `+0x84`, since it uses the entity’s `+0x78` vector instead. The observed code supplies no defined fallback vector for the case where inheritance is disabled. `src/game/8006ACB0.c:166–175,236–245`, `src/game/8005EE04.c:179–186`.

8. **Sound samples slot 0 before the contact-field decrement.** The contact-field tick selects its counter using the entry’s `+0x54` index, requests sound, then decrements that indexed counter. The sound wrapper always reads the first halfword at `+0x8A`. This distinction matters when the field belongs to slot 1 or 2. `src/game/8005D8F4.c:253–289`, `src/game/8006C488.c:41–49`.

9. **Scaled-limit selection and rounding.** Signed control byte `+0xC1` selects session word `+0x08` when zero and `+0x98` for every nonzero value. The registry halfword comes from `+0x08` or `+0x28` according to the low byte of `flag`. Modes `1` and `2` use arithmetic right shifts, so signed base `-5` produces `-7` and `-8`. The loadout reset duplicates the scaling rules. `src/game/8006BD48.c:23,48–79`, `src/game/8006AB38.c:76–102`.

10. **Lob spawn request relies on retail stack layout.** The C shows separate `args` and `sub` locals. The retail request points at `$sp+0x28` and the solver writes at `$sp+0x50`, making the solved vector visible to the handler at request-data `+0x28`. The two parameter bytes written at `$sp+0x71/+0x72` become `+0x49/+0x4A` in that data. A host recorder needs to check the compiler-produced layout and read those initialized fields during the queue call. `src/game/8005E9E4.c:16–27,64–75,110–114`, `asm/us/main.s:91845–91853,91926–91934`, `src/game/80036940.c:123–140`.
